\# SNS Application



Python（Django）を使用して開発したSNSアプリケーションです。



就職活動用のポートフォリオとして制作しました。



ユーザー登録、投稿、コメント、いいね、フォローなど、SNSの基本機能を実装しています。



\## 公開URL



https://sns-project-z15x.onrender.com/



※ Renderの無料プランを使用しているため、一定時間アクセスがない場合、初回表示に時間がかかることがあります。

\## 開発で工夫した点



\### 1. 非同期通信



JavaScriptのFetch APIを使用し、いいねやコメントの操作をページ全体の再読み込みなしで反映できるようにしました。



\### 2. アクセス制御



Djangoの認証機能を使用し、ログインが必要な操作を制限しています。



投稿の編集・削除は、投稿者本人のみが行えるようにしています。



\### 3. 入力値の検証



フォームのバリデーションを利用し、空白のみのコメントや文字数制限を超える入力を防止しています。



\### 4. スマートフォン対応



CSSのメディアクエリなどを使用し、PCとスマートフォンの両方で利用できる画面構成にしました。



\### 5. 本番環境へのデプロイ



RenderとTiDB Cloudを使用して、Djangoアプリケーションをインターネット上に公開しました。



環境変数を使用して、データベースの接続情報やDjangoの秘密鍵などをソースコードから分離しています。



\## ローカル環境での起動方法



以下は一般的なセットアップ手順です。実際の起動には、必要な環境変数とデータベースの設定が必要です。



\### 1. リポジトリを取得



```bash

git clone https://github.com/abc123615/sns-project.git

cd sns-project

```



\### 2. 仮想環境を作成



```bash

python -m venv .venv

```



Windows（PowerShell）の場合：



```powershell

.\\.venv\\Scripts\\Activate.ps1

```



\### 3. ライブラリをインストール



```bash

pip install -r requirements.txt

```



\### 4. 環境変数を設定



Djangoの秘密鍵、データベース接続情報など、`config/settings.py` で参照している環境変数を設定してください。



秘密鍵やパスワードはGitHubに公開しないでください。



\### 5. マイグレーションを実行



```bash

python manage.py migrate

```



\### 6. 開発サーバーを起動



```bash

python manage.py runserver

```



ブラウザで以下のURLを開きます。



http://127.0.0.1:8000/
